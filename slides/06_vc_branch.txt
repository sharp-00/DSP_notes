_ption 1:  Clone Remote  GitHub  Repository
? Start from an existing repository hosted on GitHub
? Create a local working copy by cloning the remote repository
Steps:
1. Clone the  repository:
git clone https://github.com/user/project.git
2. Make changes locally and  commit:
git add.
git commit -m "Your message"
3. Push changes to GitHub:
git push origin main
4. Pull updates from GitHub	when needed :
git pull origin main

ption 2: Set	Remote in Existing Local Repository

? Start from an already existing local Git repository
? Later connect it to a remote GitHub repository
Steps:
1. Initialize repository locally	if not already done :
git init

2. Add GitHub repository as a remote:
git remote add origin https://github.com/user/project.git

3. Push local history to GitHub:
git push -u origin main

Note:  GitHub repository should  be empty  (no README or commits).
